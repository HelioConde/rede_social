# Rede Social — Experimento web

**Projeto legado para explorar a construção de uma interface de rede social.**

## Propósito

Investigar componentes comuns a produtos sociais, como perfil, navegação e publicação de conteúdo. A ideia representa um exercício de frontend e arquitetura de produto.

## Estado

Repositório histórico **em desenvolvimento experimental**. Não há aqui comprovação de serviço público homologado, moderação ou armazenamento seguro de contas.

## Para retomar

1. Inventariar as páginas e arquivos existentes.
2. Definir um fluxo mínimo de perfil e publicações.
3. Planejar autenticação, privacidade, moderação e proteção de dados.
4. Adicionar testes de navegação e responsividade.
